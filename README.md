# Харків Ріелтер

Преміальна нерухомість у Харкові та Харківській області.

## Опис проєкту

Вебсайт для пошуку преміальної нерухомості (квартири, будинки, пентхауси) у Харкові та Харківській області. Проєкт містить каталог об'єктів з фільтрацією, детальну інформацію про кожну пропозицію, перелік експертів агентства, інформацію про компанію та інтерактивні форми для консультацій.

## Швидкий старт

Для запуску проєкту локально виконайте наступні кроки:

1. Встановіть залежності:
   ```bash
   npm install
   ```

2. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```

3. Відкрийте [http://localhost:5173](http://localhost:5173) у браузері.

## Стек технологій

- **Фреймворк:** React (v18) з Vite
- **Стилізація:** Tailwind CSS, Framer Motion (для анімацій)
- **Маршрутизація:** React Router DOM (v6)
- **Іконки:** Lucide React
- **Робота з даними:** React Query (TanStack Query v5)

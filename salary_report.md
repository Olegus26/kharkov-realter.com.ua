📅 Отчет о проделанной работе — Разработка сайта «Харків Ріелтер» с нуля
Общее время: ~96 часов

1. Инициализация проекта, дизайн-система и базовая архитектура (~12 часов)
- Настройка и развертывание окружения React 18 с использованием сборщика Vite.
- Конфигурация Tailwind CSS, импорт и оптимизация шрифтов (Cormorant Garamond, Inter) и настройка глобальных CSS-переменных темы (темные оттенки, золото, акценты).
- Настройка клиентского роутинга с помощью React Router DOM v6, конфигурирование путей и защита маршрутов (SiteLayout).
- Интеграция и базовая настройка TanStack React Query v5 и создание Query Client для будущей работы с API.

2. Проектирование структуры данных и подготовка контента (~8 часов)
- Разработка схем данных для сущностей объектов недвижимости (Property) и риелторов (Agent), включая типы полей, перечисления (enum) и валидационные правила.
- Проектирование и наполнение качественной базы мок-данных (mockData.js), содержащей реалистичные объекты премиальной недвижимости в Харькове (адреса, цены в грн, площади, этажность) и детальные анкеты агентов.

3. Верстка и логика главной страницы и общей обвязки (~18 часов)
- Разработка адаптивного хедера (Navbar) с изменением стилей (blur/border) при скролле и анимированным мобильным меню.
- Интеграция футера (Footer) с навигацией, контактами, списком услуг и логотипами партнерских площадок (LUN, OLX, dim RIA и др.).
- Верстка Hero-секции с поисковой формой (быстрый переход к аренде/продаже и текстовому поиску по районам) и анимациями Framer Motion.
- Разработка блоков статистики (Award, Users, Home), карточек преимуществ и CTA-баннера для записи на консультацию.

4. Разработка каталога и интерактивной системы фильтрации недвижимости (~20 часов)
- Создание страницы каталога (Catalog) с выводом списка доступных объектов.
- Реализация сложного фильтра в реальном времени с использованием useMemo для исключения лишних рендеров:
  * Фильтрация по типу сделки (табы Все/Продажа/Аренда).
  * Текстовый поиск по заголовку и локации объекта.
  * Выбор категории недвижимости (квартиры, дома, пентхаусы, виллы, коммерция).
  * Ограничение диапазона цен (поля от/до).
- Создание переиспользуемой карточки объекта (PropertyCard) с анимациями зума при наведении, выводом стоимости, площади, комнатности и этажа.

5. Разработка детальной страницы объекта (Property Detail) (~16 часов)
- Верстка страницы детального просмотра объекта с хлебными крошками (Breadcrumbs) для навигации.
- Реализация интерактивной галереи изображений (переключение главного фото по клику на миниатюры с обводкой активного элемента).
- Разработка структурированной сетки технических характеристик (м², комнаты, этаж, год постройки).
- Создание боковой панели с форматированием цены в миллионы (например, 35 млн ₴), автоматическим расчетом цены за м² и кнопками быстрой связи (tel: и переход на форму).

6. Разработка разделов команды, компании и контактов (~14 часов)
- Разработка страницы экспертов (Agents) с карточками сотрудников, зум-эффектом и переходом фото из ч/б в цвет, выводом опыта, количества сделок и прямыми ссылками на звонок/почту.
- Верстка страницы «Про нас» (About) со слайдером, ценностями компании и интерактивной вертикальной линией времени (Timeline) развития агентства с 1994 по 2026 год.
- Реализация страницы контактов (Contact) с формой обратной связи (выбор темы, поля ввода, анимированный лоадер отправки, экран успешной отправки) и прокручиваемым каталогом адресов 14 офисов агентства в Харькове.

7. Тестирование, адаптация и оптимизация (~8 часов)
- Проверка кроссбраузерной совместимости и корректности отображения на мобильных экранах различных разрешений (от 320px до 1920px).
- Оптимизация анимаций Framer Motion и скролла страниц для плавного пользовательского опыта.
- Настройка базовой доступности (ARIA-атрибуты для интерактивных элементов, табиндекс для клавиатуры, семантическая верстка).
